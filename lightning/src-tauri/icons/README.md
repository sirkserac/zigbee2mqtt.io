# App-iconen

Plaats hier de gegenereerde iconen (`32x32.png`, `128x128.png`, `128x128@2x.png`,
`icon.icns`, `icon.ico`). Genereer ze uit één bronafbeelding (bij voorkeur
1024x1024 PNG) met:

```bash
npm run tauri icon path/naar/logo.png
```

Dit vult deze map automatisch met alle vereiste formaten voor Windows
(`.ico`), macOS (`.icns`) en Linux (`.png`).
